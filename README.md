# Python-snake-game
A classic Snake Game built using Python and Tkinter.
This project was created as a hands-on learning experience to explore Python programming, object-oriented programming, and GUI development.
🎮 Features:
~Snake movement using arrow keys
~Random food generation
~Score tracking
~Wall collision detection
~Self-collision detection
~Game Over screen
✉️ Libraries:
~Tkinter
~Random
